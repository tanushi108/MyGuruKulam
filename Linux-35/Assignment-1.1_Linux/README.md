# 🎓 Learning Outcomes

After completing this assignment, you will be able to:

- ✅ Navigate directories in Linux.
- ✅ Create and remove directories.
- ✅ Create files without using a text editor.
- ✅ Append and prepend content to files.
- ✅ Display specific lines from a file.
- ✅ List files and directories using different commands.
- ✅ Copy, rename, move, clear, and delete files.
